# Smart Agriculture and Rural Development using IoT and Machine Learning

This repository contains a static web app for a project titled **Smart Agriculture and Rural Development using IoT and Machine Learning**.

## Live Website

Visit the project website:

https://hansikaalivelli-alt.github.io/smart-agri/

## Features

- Responsive homepage for the project
- IoT field dashboard with simulated live sensor values
- Crop recommendation advisor using rule-based ML-style logic
- IoT architecture section
- Rural development benefits section
- GitHub Pages-ready static website

## Project Modules

1. **IoT Monitoring**: Tracks temperature, humidity, soil moisture, and rainfall chance.
2. **Machine Learning Advisor**: Recommends suitable crops from field inputs.
3. **Smart Irrigation Support**: Helps farmers decide when irrigation may be required.
4. **Rural Development**: Promotes water conservation, productivity, awareness, and digital inclusion.

## How to Run

Open `index.html` in a browser.

## GitHub Pages Deployment

After pushing this repository to GitHub:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Go to **Pages**.
4. Select branch `master` or `main`.
5. Select folder `/root`.
6. Save.

Your web page link will look like:

```text
https://hansikaalivelli-alt.github.io/REPOSITORY-NAME/
```

Replace `REPOSITORY-NAME` with the exact GitHub repository name.
